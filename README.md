# one-word-first-thought

An entry for make.fun's [One Word, First Thought](https://make.fun/bounty/u-0xkianno-one-word-first-thought-106abaf8) bounty.

`main.py` writes exactly one word, the first that comes to mind, to
`/output/entry.txt` with no trailing newline:

```
Coffee.
```

Before writing, it checks the word is a single word of 1 to 24
characters, which is what the bounty gate accepts.

## Layout

- `main.py` - the entry program (Python 3, no dependencies)
